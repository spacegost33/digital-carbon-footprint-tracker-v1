AGENT SETUP

How device monitoring works

  1. Enroll a device and copy its one-time token.
  2. Install the agent and configure the API URL and token.
  3. The agent periodically sends CPU, memory and runtime observations.
  4. The agent estimates electricity consumption using a configured device power profile. Carbon emissions are calculated automatically and displayed in your Overview.
  5. Keep the monitoring agent running on your device to continue collecting observations,even when the web app is closed.

Never share device tokens. Revoke a device immediately if its token is exposed.
