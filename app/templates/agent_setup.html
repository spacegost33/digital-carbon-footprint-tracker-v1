CARBONTRACK AGENT V3

Monitor an authorized computer

Enroll a Windows, Linux or macOS computer in Devices & agents and copy its one-time token. The agent measures CPU and RAM usage, runtime and supported sensors; whole-device electricity remains an estimate.

Windows executable

Download the unsigned executable and its SHA256 file from the release after the GitHub build workflow publishes them. No Python installation is needed. Check the checksum and source before running.

Windows release ↗ Download .exe SHA256 checksum

The release must be built by the project maintainer. If it is unavailable, use the Python download.

Python source (all supported OS)

Extract the ZIP, install its requirements and run python agent.py. Existing .env configuration works; otherwise the agent prompts for setup.

Download Python agent

First run and optional startup

  1. Open the executable. Confirm that you are authorized to monitor the computer.
  2. Enter your CarbonTrack HTTPS URL, token, reporting interval and calibrated idle/load watts. Example defaults are assumptions.
  3. Keep the visible console running; Ctrl+C stops collection. Completed unsent records remain in a local SQLite queue.
  4. Windows only: run .\CarbonTrack-Agent.exe --enable-startup and explicitly confirm. Remove it with .\CarbonTrack-Agent.exe --disable-startup. The executable must remain in the same location.

Use one agent per computer. Revoke the token in Devices & agents to stop future uploads. No browser history, screenshots or file contents are collected. Local tokens are stored in the user profile (not encrypted by this agent); protect the account and revoke exposed tokens. Queue records are isolated by endpoint and token, retained until acknowledged, and rejected records remain local for inspection.

Latest hardware observations

Component readings are diagnostic only. They are not added to estimated whole-device energy. Unsupported sensors are unavailable, not zero. GPU watts are a point reading; CPU package Wh applies to a collection interval. Received time is distinct from observation time.
